# AMUNÌ — MVP

**Every day, a possibility.**

AMUNÌ is a technology-focused web platform concept designed to provide a simple, modern, and transparent way to discover products and explore prize-based initiatives.

The project aims to combine a premium digital experience with an accessible and user-friendly interface.

> **Project status:** In development

## ✨ Project Goals

- Build a clean, responsive, and intuitive user interface.
- Create a product catalog with a grid layout and search functionality.
- Display product details in a modal popup.
- Include a countdown timer for each product initiative.
- Keep product information organized in JavaScript data structures.
- Prioritize transparency, usability, and maintainable code.

## 🛍️ Planned Features

### Product Catalog
A simple product grid with a search field to help users find products quickly.

### Product Details Modal
Clicking a product opens a modal containing its image, title, description, specifications, price, and relevant initiative information.

### Countdown Timer
Each initiative can display a countdown based on its configured closing date and time.

### Responsive Design
The interface is designed to work across desktop, tablet, and mobile devices.

### JavaScript Data Management
During the MVP stage, product information will be stored in an array of objects in JavaScript rather than a database.

### Image Management
Product images will be stored in the repository under `assets/images/` and optimized for web performance.
